An open-world crime game in the spirit of GTA 6, built for the make.fun gta6-01 bounty: a sun-soaked coastal city to explore on foot and by car, with traffic and pedestrians, cars to steal and drive, a wanted level with police who respond, missions and a story, combat, a HUD with a minimap, a start screen and a save.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Keyboard and mouse only, no network needed.
